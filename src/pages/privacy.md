# Privacy and opt-out

## What we use

Only public data from GitHub profiles: your numeric account ID, login, follower count and contribution counts for the last 12 months. We do not store your name, email, bio, company, status or the exact text of your location. Data is not sold and not shared with recruiters or job boards.

## Remove yourself

**Option 1 — GitHub status (no contact with us).** Set your GitHub status to a message containing `contributors.top opt-out`, visible to everyone, with "Clear after: Don't clear". You are removed from all rankings and badges the next time your country is updated (within about two days). After that you can remove the status; the opt-out stays.

**Option 2 — an issue.** Open a [remove-me issue](https://github.com/contributors-top/contributors.top/issues/new?template=remove-me.yml). It is processed automatically within minutes and moved out of the public repository.

We keep only a keyed hash of your account ID so that you are not added back. To return, set a status containing `contributors.top opt-in`.

## What we cannot control

Copies made before removal: old commits of the public repository, web archives, forks and search engine caches. Avatars are loaded from GitHub's servers, so GitHub sees the visitor's IP address. The site uses no analytics and no cookies.
