# プライバシーとオプトアウト

## 使用するデータ

GitHubプロフィールの公開データのみです：数値のアカウントID、ユーザー名、フォロワー数、過去12か月のコントリビューション数。表示名、メールアドレス、自己紹介、会社、ステータス、所在地の正確な文字列は保存しません。データを販売したり、リクルーターや求人サイトに提供したりすることはありません。

## 掲載を取りやめる

GitHubのステータスを `contributor.top opt-out` を含むメッセージにし、全員に公開して「Clear after: Don't clear」に設定してください。次にあなたの国が更新されたとき（およそ2日以内）に、すべてのランキングとバッジから削除されます。あなたの国の更新が失敗し続けている場合でも、ステータスはコレクターの実行開始時に毎回確認されます。その後はステータスを消しても構いません。オプトアウトは維持されます。

フォームやIssueをあえて用意していないのは、公開の依頼ではあなたのユーザー名と削除が永久に結びついてしまうからです。ステータスなら私たちへの連絡は不要で、本人のプロフィールからしか読み取らないため、誰も他人を削除したり追加したりできません。

再び追加されないように、アカウントIDの鍵付きハッシュだけを、実行のたびに再暗号化される暗号化リストに保存します。このリストからは、誰がオプトアウトしたかも、何人が、いつオプトアウトしたかも読み取れません。戻りたい場合は、`contributor.top opt-in` を含むステータスを設定してください。

## 私たちが管理できないもの

削除前に作られたコピー：公開リポジトリの過去のコミット、ウェブアーカイブ、フォーク、検索エンジンのキャッシュ。ランキングを時系列で比べれば、誰でもあなたが載らなくなったことに気づけます。これは引っ越した人や上位から外れた人と同じです。アバターはGitHubのサーバーから読み込まれ、各ページはリポジトリのスター数をGitHubのAPIに問い合わせるため、GitHubには訪問者のIPアドレスが見えます。このサイトはアクセス解析もCookieも使いません。
