# 集計方法

## 対象となる人

1. 国ごとに、プロフィールの**所在地**がその国または国内の都市に一致するユーザーをGitHubで検索します。各国の所在地文字列のリストは [`presets/`](https://github.com/contributor-top/contributor.top/tree/main/presets) にあり、プルリクエストを受け付けています。
2. GitHubの検索はコントリビューション数で並べ替えられないため、一致したユーザーのうち**フォロワー数上位{{consider}}人**だけを対象にランキングします。各国のページには、対象者の中で最もフォロワーが少ない人の実際のフォロワー数が表示されます。
3. Organizationとボットは除外します。
4. 各ユーザーはちょうど**1つ**の国に属します。プロフィールの所在地で最初に挙げられた国です。複数の国が書かれている場合は、最初の国だけが数えられます。

## 集計するもの

過去12か月のコントリビューションを、GitHubがプロフィールで数えるとおりに集計します。

- **公開コントリビューション**：誰でも見られるコミット、プルリクエスト、Issue、レビュー。
- **全コントリビューション**：公開と非公開の合計。非公開のコントリビューションは、プロフィールに表示することを選んだ人の分だけが数えられます。それ以外の人については、このタブにも公開と同じ数が表示されます。
- **コミット**：公開コミットのみ。

同数の場合はフォロワー数、次にユーザー名の順で順位を決めます。

各名前の下には、`C` 公開コミット、`PR` プルリクエスト、`IS` Issue、`RV` レビュー、そして非公開コントリビューションを表す鍵が表示されます（カーソルを合わせると正確な数が表示されます）。

## マークと除外

誰にでも同じに適用されるいくつかのルールによって、確認できない数値やスクリプトが生み出した数値がランキングを左右しないようにしています。ランキングの各マークにカーソルを合わせると、その根拠となるルールと適用された数値が表示されます。

| ルール                 | 条件                                                                                                                                            | 扱い                                                         |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| ほぼ非公開             | コントリビューションの{{private_flag}}%以上が非公開                                                                                             | **全コントリビューション**で合計の横に鍵を表示               |
| 公開分がほぼない       | 公開コントリビューションが合計の{{min_public}}%未満                                                                                             | **全コントリビューション**から除外（他のランキングには掲載） |
| コミットファーム       | コミットが{{min_commits}}件以上で、プルリクエスト・Issue・レビューの合計の{{ratio}}倍以上                                                       | すべてのランキングから除外                                   |
| ひっそりしたリポジトリ | コミットが{{min_commits}}件以上で、その{{quiet_share}}%以上がスター{{quiet_stars}}未満の自分のリポジトリ1つに集中                               | コミットファームと同じ                                       |
| 例外                   | コミットの{{popular_share}}%以上が、スター{{popular_stars}}以上の他人のリポジトリ、またはそうしたリポジトリを持つ組織の任意のリポジトリへのもの | 自動化とは判定しない                                         |

GitHubは非公開の活動を、分割も検証もできない1つの数値として報告します。そのため、公開の活動に裏付けられている場合にのみ数えます。クローズドソースで働く人も多いため、鍵だけで除外されることはありません。大規模なコミュニティプロジェクトやLinuxディストリビューションのメンテナーのように、広く使われているプロジェクトへ直接コミットする人は自動化とは判定しません。そこにコミットする権限を与えられるのはプロジェクト自身だけだからです。

## ランキングの検証

ランキングはこれらのルールと上記の並び順だけに従い、手作業で順位を動かすことはありません。しきい値は[`config.yml`](https://github.com/contributor-top/contributor.top/blob/main/config.yml)にあり、その中の唯一の手動リスト`denylist_ids`は公開のプルリクエストでしか変更されません。各国について収集した数値はリポジトリの[`data`ブランチ](https://github.com/contributor-top/contributor.top/tree/data)にあるため、どのランキングも再計算して検証できます。

## 自分が載っていないのはなぜ？

- プロフィールの所在地が、自分の国のプリセットのどの文字列にも一致していない。所在地は自由記述なので、都市名や国名を書き加えるか、プリセットにプルリクエストを送ってください。
- 自分の国でフォロワー数上位{{consider}}人に入っていない。
- コントリビューションのほとんどが非公開（公開分が{{min_public}}%未満）の場合、**全コントリビューション**にだけ載りません。
- コミットが自動化されているように見える（上記のルールを参照）：そのようなアカウントはどのランキングにも載りません。
- コントリビューションが非公開で、プロフィールに表示されていない。
- 削除を依頼した（[プライバシーとオプトアウト](/ja/privacy/)を参照）。

## データへのアクセス

各ランキングはJSONでも提供しています。[`/api/index.json`](/api/index.json) には国の一覧が、`/api/<country>.json`（例：`/api/canada.json`）には順位、ユーザー名、コントリビューション数を含む3つのランキングすべてが入っています。世界ランキングは [`/api/world.json`](/api/world.json) にあります。ファイルは静的で、どのサイトからでも取得できます。

オープンソースの研究、統計、コミュニティプロジェクトに使ってください。人への一斉連絡、採用のための声かけ、データの転売には使わないでください。オプトアウトした人が含まれることはありません。

## 更新

国は、最後の更新が最も古いものから順に1つずつ更新されます。各国のページには最終更新日時が表示されます。

[committers.top](https://committers.top) に着想を得ています。
