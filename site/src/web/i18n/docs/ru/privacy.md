# Приватность и отказ

## Что мы используем

Только публичные данные из профилей GitHub: числовой ID аккаунта, логин, отображаемое имя, число подписчиков и число вкладов за последние 12 месяцев. Отображаемое имя показывается рядом с логином на сайте, как на GitHub, но не входит в JSON-файлы; оно меняется, когда вы меняете его на GitHub, при следующем обновлении вашей страны. Мы не храним ваш email, описание, компанию, статус и точный текст местоположения. Данные не продаются и не передаются рекрутерам или сайтам вакансий.

## Как удалиться

Установите на GitHub статус с текстом, содержащим `contributor.top opt-out`, видимый всем, с «Clear after: Don't clear». Вы будете удалены из всех рейтингов и бейджей при следующем обновлении вашей страны (примерно в течение двух дней); если обновление вашей страны раз за разом не удаётся, статус всё равно проверяется в начале каждого запуска сборщика. После этого статус можно убрать: отказ сохранится.

Формы или issue для этого нет намеренно: публичный запрос навсегда связал бы ваш логин с удалением. Статус не требует связываться с нами и читается только из вашего собственного профиля, поэтому никто не может удалить или добавить кого-то другого.

Мы храним только хеш с ключом от ID вашего аккаунта, чтобы вас не добавили обратно, в зашифрованном списке, который заново шифруется при каждом запуске: из него нельзя узнать ни кто, ни сколько людей отказались, ни когда. Чтобы вернуться, установите статус, содержащий `contributor.top opt-in`.

## Что мы не можем контролировать

Копии, сделанные до удаления: старые коммиты публичного репозитория, веб-архивы, форки и кеши поисковиков. Любой, кто сравнивает рейтинги во времени, увидит, что вас больше нет в списке, как и с любым, кто переехал или выпал из топа. Аватары загружаются с серверов GitHub, и каждая страница запрашивает у API GitHub число звёзд репозитория, поэтому GitHub видит IP-адрес посетителя. На сайте нет аналитики и cookies.
