# Privasi dan keluar dari peringkat

## Data yang kami gunakan

Hanya data publik dari profil GitHub: ID akun numerik, nama pengguna, nama tampilan, jumlah pengikut, dan jumlah kontribusi Anda selama 12 bulan terakhir. Nama tampilan ditampilkan di samping nama pengguna Anda di situs, seperti di GitHub, tetapi tidak termasuk dalam file JSON; nama ini ikut berubah saat Anda mengubahnya di GitHub, pada pembaruan negara Anda berikutnya. Kami tidak menyimpan email, bio, perusahaan, status, atau teks lengkap lokasi Anda. Data tidak dijual dan tidak dibagikan kepada perekrut atau situs lowongan kerja.

## Hapus diri Anda

Atur status GitHub Anda ke pesan yang berisi `contributor.top opt-out`, terlihat oleh semua orang, dengan "Clear after: Don't clear". Anda akan dihapus dari semua peringkat dan badge pada pembaruan negara Anda berikutnya (dalam sekitar dua hari); jika pembaruan negara Anda terus gagal, status tetap diperiksa di awal setiap proses pengumpulan data. Setelah itu Anda boleh menghapus status tersebut; Anda tetap keluar dari peringkat.

Sengaja tidak ada formulir atau issue yang perlu diisi: permintaan publik akan mengaitkan nama pengguna Anda dengan penghapusan itu selamanya. Status tidak memerlukan kontak dengan kami dan hanya dibaca dari profil Anda sendiri, sehingga tidak ada yang bisa menghapus atau menambahkan orang lain.

Kami hanya menyimpan hash berkunci dari ID akun Anda agar Anda tidak ditambahkan kembali, dalam daftar terenkripsi yang dienkripsi ulang setiap kali proses berjalan: dari daftar itu tidak bisa diketahui siapa yang keluar, berapa banyak, maupun kapan. Untuk kembali, atur status yang berisi `contributor.top opt-in`.

## Yang tidak bisa kami kendalikan

Salinan yang dibuat sebelum penghapusan: commit lama di repositori publik, arsip web, fork, dan cache mesin pencari. Siapa pun yang membandingkan peringkat dari waktu ke waktu bisa melihat bahwa Anda tidak lagi tercantum, sama seperti orang yang pindah negara atau keluar dari posisi teratas. Avatar dimuat dari server GitHub, dan setiap halaman meminta jumlah bintang repositori ke API GitHub, sehingga GitHub melihat alamat IP pengunjung. Situs ini tidak memakai analitik maupun cookie.
