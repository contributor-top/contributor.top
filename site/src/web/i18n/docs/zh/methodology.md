# 方法说明

## 哪些人会被收录

1. 对于每个国家，我们在 GitHub 上搜索个人资料中**所在地**与该国家或其某个城市匹配的用户。每个国家的所在地字符串列表位于 [`presets/`](https://github.com/contributor-top/contributor.top/tree/main/presets)，欢迎提交拉取请求。
2. GitHub 搜索无法按贡献排序，因此在所有匹配的用户中，我们只取**关注者最多的 {{consider}} 位用户**进行排名。每个国家的页面都会显示被考察者中关注者最少的那位的实际关注者数。
3. 组织和机器人账号不包括在内。
4. 每个人只属于**一个**国家：即个人资料所在地中最先提到的那个国家。如果列出了多个国家，只计第一个。

## 统计什么

过去 12 个月的贡献，统计方式与 GitHub 个人资料上的一致：

- **公开贡献**——所有人可见的提交、拉取请求、议题和审查。
- **全部贡献**——公开贡献加私有贡献。私有贡献只计入选择在个人资料中显示它们的用户；对于其他人，此标签页显示的数字与公开贡献相同。
- **提交**——仅公开提交。

贡献数相同时，先按关注者数排序，再按用户名排序。

每个名字下方：`C` 为公开提交，`PR` 为拉取请求，`IS` 为议题，`RV` 为审查，锁形图标表示私有贡献（悬停可查看确切数字）。

## 标记与排除

几条对所有人一视同仁的规则，避免无法核实或由脚本刷出的数字左右排名。将鼠标悬停在排名中的任一标记上，即可看到它依据的规则和所用的数字。

| 规则             | 条件                                                                                                           | 处理                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 几乎全部私有     | {{private_flag}}% 或以上的贡献为私有                                                                           | 在**全部贡献**中，总数旁显示锁                 |
| 几乎没有公开贡献 | 公开贡献低于总数的 {{min_public}}%                                                                             | 不计入**全部贡献**，其他排名照常               |
| 提交农场         | 提交 {{min_commits}} 次或以上，且至少是拉取请求、议题和审查总和的 {{ratio}} 倍                                 | 国家排名中显示机器人；不计入全球排名和全球徽章 |
| 一个冷清的仓库   | 提交 {{min_commits}} 次或以上，其中 {{quiet_share}}% 或以上集中在自己一个星标少于 {{quiet_stars}} 的仓库       | 与提交农场相同                                 |
| 例外             | {{popular_share}}% 或以上的提交进入他人星标 {{popular_stars}} 或以上的仓库，或进入拥有此类仓库的组织的任意仓库 | 永不标记为自动化                               |

GitHub 只以一个无法拆分、也无法核实的数字报告私有活动，因此只有在公开工作作为支撑时才计入；仅有锁标记不会移除任何人，因为很多人从事闭源工作。像大型社区项目和 Linux 发行版的维护者那样直接向广泛使用的项目提交的人，不会被视为自动化：只有项目本身才能授予他们提交权限。

## 如何核对排名

排名只遵循这些规则和上述排序方式，不会手动调整任何人的位置。各项阈值来自 [`config.yml`](https://github.com/contributor-top/contributor.top/blob/main/config.yml)，其中唯一的手动名单 `denylist_ids` 只能通过公开的拉取请求修改。为每个国家收集的数字都在仓库的 [`data` 分支](https://github.com/contributor-top/contributor.top/tree/data)中，因此任何排名都可以重新计算并核对。

## 为什么我不在榜上？

- 你的个人资料所在地与你所在国家预设中的任何字符串都不匹配。所在地是自由文本：填写你的城市或国家，或者向预设提交拉取请求。
- 你不在你所在国家关注者最多的 {{consider}} 位用户之中。
- 你的贡献几乎全部为私有（公开部分低于 {{min_public}}%）：这种情况下你只是不会出现在**全部贡献**中。
- 你的贡献是私有的，且未在个人资料中显示。
- 你要求了移除（见[隐私与退出](/zh/privacy/)）。

## 数据获取

每个排名也以 JSON 格式提供：[`/api/index.json`](/api/index.json) 列出所有国家，`/api/<country>.json`（例如 `/api/canada.json`）包含全部三个排名，附有名次、用户名和贡献数。全球排名位于 [`/api/world.json`](/api/world.json)。这些文件是静态的，可以从任何网站获取。

可将它们用于开源研究、统计和社区项目。请勿用于批量联系他人、招聘外联或转售数据。已选择退出的人永远不会被包含在内。

## 更新

各国依次更新，最久未更新的国家优先。每个国家的页面都会显示上次更新的时间。

灵感来自 [committers.top](https://committers.top)。
