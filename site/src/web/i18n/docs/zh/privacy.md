# 隐私与退出

## 我们使用的数据

仅使用 GitHub 个人资料中的公开数据：你的数字账号 ID、用户名、关注者数，以及过去 12 个月的贡献数。我们不存储你的显示名称、邮箱、个人简介、公司、状态或所在地的原文。数据不会出售，也不会提供给招聘人员或招聘网站。

## 将自己移除

将你的 GitHub 状态设置为包含 `contributor.top opt-out` 的消息，对所有人可见，并选择“Clear after: Don't clear”。在你所在国家下次更新时（大约两天内），你会从所有排名和徽章中移除；如果你所在国家的更新一直失败，每次收集程序开始运行时仍会检查该状态。之后你可以删除该状态，退出依然有效。

我们特意不提供表单或议题来提交申请：公开的请求会让你的用户名永远与移除联系在一起。设置状态无需联系我们，而且只从你自己的个人资料中读取，因此任何人都无法移除或添加他人。

为了不让你被重新加入，我们只保存你账号 ID 的带密钥哈希，存放在一个每次运行都会重新加密的加密列表中：从中既无法得知谁退出、有多少人退出，也无法得知何时退出。如需回来，请设置包含 `contributor.top opt-in` 的状态。

## 我们无法控制的内容

移除之前产生的副本：公开仓库的旧提交、网页存档、复刻和搜索引擎缓存。任何对比不同时期排名的人都能看出你已不在榜上，正如能看出任何搬走或跌出前列的人一样。头像从 GitHub 的服务器加载，每个页面都会向 GitHub API 请求该仓库的星标数，因此 GitHub 能看到访问者的 IP 地址。本网站不使用任何分析工具，也不使用 Cookie。
