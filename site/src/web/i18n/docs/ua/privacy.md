# Приватність і відмова

## Що ми використовуємо

Лише публічні дані з профілів GitHub: числовий ID акаунта, логін, відображуване ім’я, кількість підписників і кількість внесків за останні 12 місяців. Відображуване ім’я показується поруч із логіном на сайті, як на GitHub, але не входить до JSON-файлів; воно змінюється, коли ви змінюєте його на GitHub, під час наступного оновлення вашої країни. Ми не зберігаємо ваш email, опис, компанію, статус і точний текст локації. Дані не продаються і не передаються рекрутерам чи сайтам вакансій.

## Як видалитися

Встановіть на GitHub статус із текстом, що містить `contributor.top opt-out`, видимий усім, з «Clear after: Don't clear». Вас буде видалено з усіх рейтингів і бейджів під час наступного оновлення вашої країни (приблизно протягом двох днів); якщо оновлення вашої країни раз у раз не вдається, статус однаково перевіряється на початку кожного запуску збирача. Після цього статус можна прибрати: відмова збережеться.

Форми чи issue для цього навмисно немає: публічний запит назавжди пов’язав би ваш логін із видаленням. Статус не вимагає зв’язуватися з нами і зчитується лише з вашого власного профілю, тому ніхто не може видалити чи додати когось іншого.

Ми зберігаємо лише хеш із ключем від ID вашого акаунта, щоб вас не додали знову, у зашифрованому списку, який заново шифрується під час кожного запуску: з нього не можна дізнатися ні хто, ні скільки людей відмовилися, ні коли. Щоб повернутися, встановіть статус, що містить `contributor.top opt-in`.

## Що ми не можемо контролювати

Копії, зроблені до видалення: старі коміти публічного репозиторію, вебархіви, форки та кеші пошукових систем. Будь-хто, хто порівнює рейтинги з часом, побачить, що вас більше немає у списку, як і будь-кого, хто переїхав або випав із топу. Аватари завантажуються із серверів GitHub, і кожна сторінка запитує в API GitHub кількість зірок репозиторію, тому GitHub бачить IP-адресу відвідувача. На сайті немає аналітики та cookies.
