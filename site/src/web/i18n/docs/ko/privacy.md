# 개인정보 보호 및 제외 요청

## 사용하는 데이터

GitHub 프로필의 공개 데이터만 사용합니다: 숫자로 된 계정 ID, 사용자 이름, 표시 이름, 팔로워 수, 최근 12개월간의 기여 수. 표시 이름은 GitHub에서처럼 사이트에서도 사용자 이름 옆에 표시되지만 JSON 파일에는 포함되지 않으며, GitHub에서 바꾸면 다음에 내 국가가 업데이트될 때 함께 바뀝니다. 이메일, 소개, 회사, 상태 메시지, 위치의 정확한 문구는 저장하지 않습니다. 데이터는 판매하지 않으며 채용 담당자나 구인 사이트에 제공하지도 않습니다.

## 목록에서 빠지기

GitHub 상태를 `contributor.top opt-out`이 포함된 메시지로 설정하고, 모두에게 공개하며, “Clear after: Don't clear”로 지정하세요. 다음에 내 국가가 업데이트될 때(약 이틀 이내) 모든 순위와 배지에서 삭제됩니다. 내 국가의 업데이트가 계속 실패하더라도, 상태는 수집기가 실행될 때마다 시작 시점에 확인됩니다. 그 후에는 상태를 지워도 되며, 제외는 유지됩니다.

신청 양식이나 이슈는 일부러 두지 않았습니다. 공개적으로 요청하면 사용자 이름이 삭제 사실과 영원히 연결되기 때문입니다. 상태는 저희에게 연락할 필요가 없고 본인 프로필에서만 읽으므로, 누구도 다른 사람을 삭제하거나 추가할 수 없습니다.

다시 추가되지 않도록 계정 ID의 키 기반 해시만 보관하며, 이는 실행할 때마다 다시 암호화되는 암호화 목록에 들어 있습니다. 이 목록으로는 누가, 몇 명이, 언제 제외를 요청했는지 알 수 없습니다. 다시 포함되려면 `contributor.top opt-in`이 포함된 상태를 설정하세요.

## 저희가 통제할 수 없는 것

삭제 전에 만들어진 사본: 공개 저장소의 과거 커밋, 웹 아카이브, 포크, 검색 엔진 캐시. 시간에 따라 순위를 비교하면 누구든 내가 더 이상 목록에 없다는 것을 알 수 있습니다. 이사했거나 상위권에서 밀려난 사람과 마찬가지입니다. 아바타는 GitHub 서버에서 불러오고, 각 페이지는 GitHub API에 저장소의 스타 수를 요청하므로 GitHub는 방문자의 IP 주소를 볼 수 있습니다. 이 사이트는 분석 도구와 쿠키를 사용하지 않습니다.
