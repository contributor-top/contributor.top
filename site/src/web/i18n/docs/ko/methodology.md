# 산정 방식

## 집계 대상

1. 국가마다 프로필 **위치**가 해당 국가나 그 국가의 도시 중 하나와 일치하는 사용자를 GitHub에서 검색합니다. 국가별 위치 문자열 목록은 [`presets/`](https://github.com/contributor-top/contributor.top/tree/main/presets)에 있으며, 풀 리퀘스트로 누구나 수정을 제안할 수 있습니다.
2. GitHub 검색은 기여 수로 정렬할 수 없으므로, 일치하는 사용자 중 **팔로워가 가장 많은 {{consider}}명**만 골라 순위를 매깁니다. 각 국가 페이지에는 대상자 중 팔로워가 가장 적은 사람의 실제 팔로워 수가 표시됩니다.
3. 조직과 봇은 제외됩니다.
4. 모든 사용자는 정확히 **하나의** 국가에 속합니다. 프로필 위치에서 처음 언급된 국가입니다. 여러 국가가 적혀 있으면 첫 번째 국가만 집계됩니다.

## 집계 항목

GitHub가 프로필에서 집계하는 방식 그대로, 최근 12개월간의 기여를 셉니다.

- **공개 기여** — 모두에게 보이는 커밋, 풀 리퀘스트, 이슈, 리뷰.
- **전체 기여** — 공개 기여와 비공개 기여의 합. 비공개 기여는 프로필에 표시하기로 선택한 사람만 집계되며, 나머지 사람은 이 탭에서도 공개 기여와 같은 숫자가 표시됩니다.
- **커밋** — 공개 커밋만.

동점이면 팔로워 수, 그다음 사용자 이름 순으로 정합니다.

각 이름 아래에는 `C` 공개 커밋, `PR` 풀 리퀘스트, `IS` 이슈, `RV` 리뷰, 그리고 비공개 기여를 나타내는 자물쇠가 표시됩니다(마우스를 올리면 정확한 숫자가 보입니다).

## 표시와 제외

모두에게 똑같이 적용되는 몇 가지 규칙이, 확인할 수 없거나 스크립트가 만든 숫자가 순위를 좌우하지 않도록 막습니다. 순위의 각 표시에 마우스를 올리면 그 근거가 된 규칙과 적용된 숫자가 보입니다.

| 규칙                  | 조건                                                                                                                               | 결과                                       |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 대부분 비공개         | 기여의 {{private_flag}}% 이상이 비공개                                                                                             | **전체 기여**에서 합계 옆에 자물쇠 표시    |
| 공개 기여가 거의 없음 | 공개 기여가 전체의 {{min_public}}% 미만                                                                                            | **전체 기여**에서 제외, 다른 순위에는 유지 |
| 커밋 팜               | 커밋 {{min_commits}}개 이상, 풀 리퀘스트·이슈·리뷰 합계의 {{ratio}}배 이상                                                         | 모든 순위에서 제외                         |
| 조용한 저장소 하나    | 커밋 {{min_commits}}개 이상, 그중 {{quiet_share}}% 이상이 별 {{quiet_stars}}개 미만인 본인 저장소 하나에 집중                      | 커밋 팜과 동일                             |
| 예외                  | 커밋의 {{popular_share}}% 이상이 별 {{popular_stars}}개 이상인 다른 사람의 저장소, 또는 그런 저장소가 있는 조직의 아무 저장소로 감 | 자동화로 표시하지 않음                     |

GitHub는 비공개 활동을 나누거나 검증할 수 없는 하나의 숫자로 제공하므로, 공개 활동이 뒷받침할 때만 집계합니다. 비공개 코드로 일하는 사람이 많기 때문에 자물쇠만으로 제외되는 사람은 없습니다. 대규모 커뮤니티 프로젝트나 리눅스 배포판 메인테이너처럼 널리 쓰이는 프로젝트에 직접 커밋하는 사람은 자동화로 보지 않습니다. 그곳에 커밋할 권한은 프로젝트만 줄 수 있기 때문입니다.

## 순위 검증하기

순위는 이 규칙들과 위의 정렬 순서만 따르며, 누구도 손으로 옮기지 않습니다. 기준값은 [`config.yml`](https://github.com/contributor-top/contributor.top/blob/main/config.yml)에 있고, 그 안의 유일한 수동 목록인 `denylist_ids`는 공개 풀 리퀘스트로만 바뀝니다. 국가마다 수집한 숫자는 저장소의 [`data` 브랜치](https://github.com/contributor-top/contributor.top/tree/data)에 있으므로, 어떤 순위든 다시 계산해 검증할 수 있습니다.

## 왜 제가 목록에 없나요?

- 프로필 위치가 내 국가 프리셋의 어떤 문자열과도 일치하지 않습니다. 위치는 자유 텍스트이므로 도시나 국가를 적거나, 프리셋에 풀 리퀘스트를 보내 주세요.
- 내 국가에서 팔로워가 가장 많은 {{consider}}명 안에 들지 않습니다.
- 기여 대부분이 비공개입니다(공개 기여 {{min_public}}% 미만). 이 경우 **전체 기여**에서만 제외됩니다.
- 커밋이 자동화된 것으로 보입니다(위 규칙 참고). 이런 계정은 어떤 순위에도 들어가지 않습니다.
- 기여가 비공개이고 프로필에 표시되지 않습니다.
- 삭제를 요청했습니다([개인정보 보호 및 제외 요청](/ko/privacy/) 참고).

## 데이터 접근

모든 순위는 JSON으로도 제공됩니다. [`/api/index.json`](/api/index.json)에는 국가 목록이, `/api/<country>.json`(예: `/api/canada.json`)에는 순위, 사용자 이름, 기여 수가 담긴 세 가지 순위가 모두 들어 있습니다. 세계 순위는 [`/api/world.json`](/api/world.json)에 있습니다. 파일은 정적이며 어느 사이트에서든 가져올 수 있습니다.

오픈 소스 연구, 통계, 커뮤니티 프로젝트에 사용하세요. 사람들에게 대량으로 연락하거나, 채용 홍보를 하거나, 데이터를 재판매하는 데 사용하지 마세요. 제외를 요청한 사람은 절대 포함되지 않습니다.

## 업데이트

국가는 가장 오래전에 업데이트된 국가부터 차례로 업데이트됩니다. 각 국가 페이지에는 마지막 업데이트 시각이 표시됩니다.

[committers.top](https://committers.top)에서 영감을 받았습니다.
