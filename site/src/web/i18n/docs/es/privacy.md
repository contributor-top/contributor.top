# Privacidad y exclusión

## Qué usamos

Solo datos públicos de los perfiles de GitHub: el ID numérico de tu cuenta, tu nombre de usuario, tu número de seguidores y tus contribuciones de los últimos 12 meses. No guardamos tu nombre visible, tu email, tu biografía, tu empresa, tu estado ni el texto exacto de tu ubicación. Los datos no se venden ni se comparten con reclutadores ni portales de empleo.

## Cómo quitarte

Pon en GitHub un estado con un mensaje que contenga `contributor.top opt-out`, visible para todos, con "Clear after: Don't clear". Se te quitará de todos los rankings e insignias en la siguiente actualización de tu país (en unos dos días); si la actualización de tu país sigue fallando, el estado se comprueba igualmente al inicio de cada ejecución del recolector. Después puedes quitar el estado: la exclusión se mantiene.

A propósito, no hay ningún formulario ni issue que rellenar: una solicitud pública vincularía tu nombre de usuario a la eliminación para siempre. El estado no requiere contactar con nosotros y solo se lee de tu propio perfil, así que nadie puede quitar ni añadir a otra persona.

Solo guardamos un hash con clave del ID de tu cuenta para no volver a añadirte, en una lista cifrada que se vuelve a cifrar en cada ejecución: de ella no se puede saber quién se excluyó, cuántas personas lo hicieron ni cuándo. Para volver, pon un estado que contenga `contributor.top opt-in`.

## Lo que no podemos controlar

Las copias hechas antes de la eliminación: commits antiguos del repositorio público, archivos web, forks y cachés de buscadores. Cualquiera que compare los rankings a lo largo del tiempo puede ver que ya no apareces, como ocurre con cualquiera que se muda o sale del top. Los avatares se cargan desde los servidores de GitHub, y cada página pide a la API de GitHub el número de estrellas del repositorio, así que GitHub ve la dirección IP del visitante. El sitio no usa analítica ni cookies.
